# 阶段三验收标准

## 范围与分层

- 推荐算法位于 `backend/app/services/recommendation_service.py`；
- 算法使用独立输入对象，不直接查询 ORM、数据库或网络；
- Router、Repository、正式 API 和 Vue 页面没有被提前实现；
- 权重、反馈调整和阈值均集中定义，没有散落的魔法数字。

## 功能

- 普通月份、跨年月份及两个边界的季节判断正确；
- inactive、禁止食用和策略明确排除的不喜欢水果不会进入候选；
- 缺失季节数据降低分数但不自动过滤；
- 六项子分数和基础总分均在 `[0, 1]`；
- 当季、喜欢、近期未推荐和价格匹配能按设计改变分数；
- 历史反馈能按设计调整偏好分，且调整有上下限；
- 第一项从接近最高分的候选中按种子可复现选择；
- 第二项使用 `0.7 * base + 0.3 * complement`，且营养互补能改变选择；
- 两项水果 ID 始终不同；
- 少于两个候选时返回可理解的领域错误；
- 每项有 2 到 4 条与真实评分一致的结构化理由；
- 理由不包含医疗诊断、治疗或药物替代承诺。

## 测试与质量

- `python -m pytest tests/services -q` 成功；
- `python -m pytest -q` 全量成功，数据库集成测试未配置时只按既有规则跳过；
- 相同输入和 `random_seed` 多次运行结果一致；
- 输入顺序不影响无随机情况下的选择；
- 空列表、缺失营养、相同营养维度和非法月份均有覆盖；
- 没有新增依赖、迁移、Supabase 写入或密钥；
- Git 秘密扫描无新增命中；
- S3 完成后 Git working tree 干净。
