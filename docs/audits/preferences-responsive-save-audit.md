# 偏好页面响应式保存审计

## 审计范围

本次只审查水果偏好选择弹窗、底部导航遮挡、移动端保存按钮和前端保存流程。未修改 FastAPI、Supabase、数据库结构、API 合同或推荐算法。

## 实施结果

- 水果列表改为独立滚动区域，弹窗底部操作栏不再随列表内容被裁剪。
- 弹窗打开时锁定页面背景滚动，并隐藏底部导航的点击层。
- 移动端弹窗使用 `100dvh` 和安全区内边距。
- 移动端页面保存栏上移，避开固定底部导航。
- `confirmPicker()`、`updateUser()` 和 `replaceFruitPreferences()` 的数据语义未改变。

## 自动化验证

- `npm test`：23 个单元测试、43 个组件测试全部通过。
- `npm run build`：生产构建成功。
- 新增 `PreferencesView` 测试，覆盖：
  - 弹窗打开/关闭时的滚动锁定；
  - 选择确认后的数字偏好 payload；
  - 用户资料先保存、水果偏好后保存；
  - 重复提交期间只发送一次请求。

| 视口 | 弹窗操作栏 | 其他结果 |
